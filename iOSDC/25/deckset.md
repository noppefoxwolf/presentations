presentation.mdはDecksetで使用するMarkdownファイルです。
スライドは`---`で区切ります。
`^`から始まる行はトークスクリプトとして使用され、スライドには表示されません。
スライドは次のスタイルで書いてください。

```markdown
# スライドのタイトル
説明（20文字程度）
- 箇条書き1
- 箇条書き2
- 箇条書き3
```

必要に応じて、スライドに１枚のみ画像を追加できます。

```markdown
![right fit](画像のパス)
```

以下のように、inlineやフルスクリーンで画像を追加することもできます。
ただし、その場合は極力文字を追加しないようにしてください。

```markdown
![inline](画像のパス)
```

```markdown
![](画像のパス)
```

章の最初や、大きく問いかけたい場合はタイトルだけのスライドを作成してください。

```markdown
# 章のタイトル
```
